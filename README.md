# Spring Boot Security Course

A demo project for learning Spring Boot Security, based on the [Amigoscode](https://www.amigoscode.com) Spring Boot Security course.

## Prerequisites

- Java 11
- Maven

## Getting Started

Clone the repository:

```bash
git clone https://github.com/amigoscode/spring-boot-security-course.git
cd spring-boot-security-course
```

Run the application:

```bash
./mvnw spring-boot:run
```

## Built With

- [Spring Boot 2.2.0](https://spring.io/projects/spring-boot)
- [Spring Security](https://spring.io/projects/spring-security)
- [Maven](https://maven.apache.org/)
